# ADR-029：到期提醒一天兩輪

- **狀態**：現行（2026-11-13）
- **修訂**：ADR-019 的到期提醒時段（每天 9 點後第一輪 → 07:00、16:00 後各一輪）與「⏰ 明天」的重推時間（隔天 9 點 → 隔天 07:00）
- **重申**：ADR-009「推過就不再推」（`notified`）不變
- **討論與草稿**：專案擁有者的 Notion（ADR-029 草稿頁）

## 決策

| # | 決策 |
| --- | --- |
| D-1 | 到期提醒（待辦＋提醒）改成台北 07:00、16:00 後各一輪，與 Gmail 控制員同時段（`DUE_CHECK_HOURS`，排程規則 `daily_hours`） |
| D-2 | 不重複推：`notified` 規則不變。16:00 那輪只會推到「07:00 之後才新增或才進入到期範圍、還沒推過」的項目；沒有就什麼都不推 |
| D-3 | 「⏰ 明天」行為不變（到期日改明天、清 `notified`），重推落在隔天 07:00 那輪；回覆文字寫明「明天 07:00 再提醒」 |
| D-4 | 推播路由、Flex 卡片、只有建立者按得動、循環提醒翻頁規則都不變 |

## 實作差異（相對 Notion 交棒頁）

- 循環提醒翻頁沒有另外加「每天只翻一次」的狀態：翻頁只動到期日早於今天的那一期，翻完就 ≥ 今天，所以同一天第二輪自然不會再翻（有測試盯著）
- 排程延遲：`daily_hours` 只補「今天已經到的最晚那個時段」，07:00 那輪拖到 16:00 後才跑的那天只跑一次
- 推播失敗的項目不標 `notified`：以前要等明天重試，現在 16:00 那輪就會再試一次
- 07:00、16:00 與 Gmail 同一輪：照排程總管既有的 4 分鐘預算，跑不完的工作留到下一輪（5 分鐘後），不會跳過

## 後果

- LINE 推播每月估計多 10～30 則，加上圖書館週報約 70～90 則，在免費 200 則內；ADR-022 的 80% 額度警告是保險
- 重複提醒仍由人決定（逐筆按 ⏰ 明天），不由系統批次重推
