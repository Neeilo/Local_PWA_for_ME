# ADR 索引與治理規則

> ADR（Architecture Decision Record）記錄「為什麼這樣做」。程式註解常寫「ADR-019 B-4」「D-8」這種編號，查它屬於哪一份決策就看這裡。狀態截至 2026-11-11。

## 治理規則（2026-11-11 決議）

1. **從下一份正式 ADR（ADR-027）起，正式生效的工程決策以 repo 的 `docs/adr/` 為準。** 專案擁有者的 Notion 保留研究、討論與草稿，並連回 repo。
2. **公開 repo 只放可公開的工程資訊**：決策、契約、取代關係、後果。決策背後的家庭與財務脈絡留在 Notion（見 [AGENTS.md](../../AGENTS.md) 公開資訊分類規則）。
3. **ADR-004 至 ADR-026 只建索引，不搬正文**；正文在 Notion，是否搬進 repo 另行決定。

另外，`tests/docs-drift.test.mjs` 會檢查程式引用到的每個 `ADR-NNN` 都出現在本索引；新增 ADR 時記得在下表加一列。

> **建議（尚未決定）**：ADR-027 起的檔名用 `NNN-短名稱.md`，至少寫背景、決策、後果、狀態、取代關係；編號不重用，被取代的不刪、改狀態並連到新的。這是撰寫本索引時的提議，格式由專案擁有者在第一份 repo ADR 時定案。
