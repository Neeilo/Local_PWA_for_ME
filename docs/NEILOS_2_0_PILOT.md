## 願景與產品界線

- Dashboard：早晨看到任務、財務、郵件、股票、天氣、閱讀摘要；按需進入完整功能。
- LINE：快速新增任務、收藏、查詢及接收既有服務結果。
- Library：IG 圖文收藏、其他網址連結保存；閱讀、個人筆記、分類、按需圖片辨識（📝 文字辨識／🤖 AI 辨識）、按需 AI 整理、可搜尋。
- 仍未完成：通用網站全文擷取、辨識文字納入搜尋、新收藏自動辨識、語意搜尋、筆電 Local Agent、安裝式插件。

## 架構與資料流程

`PWA / LINE → GAS（驗證與模組路由）→ Google Sheets／Drive`。
- Cloud-authoritative，不採全面 Local-first。
- `boot core:true` 只取必要核心與快速摘要；財務、股票延後，完整模組首次點入時再讀。
- `_module_registry`：全域功能開關；`line_users feat_*`：每人權限；兩者不可互相替代。
- `widget_config`：個人 Widget 排列／釘選／隱藏、Apps 常用、天氣地點。
- `clips`：收藏、筆記 revision、閱讀狀態、分類、AI 整理（`ai_*`）、📝 文字辨識（`ocr_*`）、🤖 AI 辨識（`vision_*`）欄位，都加在最右邊、1.0 照常讀。非 IG 目前只存 URL。
- 搜尋按下才在 GAS 比對關鍵字；不納入開機、沒有 embedding。

## 試營運驗收矩陣（須實機確認）

| 情境 | 驗收 |
|---|---|
| 冷開機 | 測 1.0/2.0 P50/P95、失敗率、相同裝置／網路條件 |
| 盤中股票 | 股票報價逾時／錯誤不影響天氣與任務；交易日與盤中顯示正確 |
| LINE → Widget | 從 LINE 建任務，首頁可讀到，完成後雲端確認；失敗不假完成 |
| 閱讀筆記衝突 | 兩裝置同時修改，第二個收到 conflict，草稿保留、不默默覆蓋 |
| Library | IG 多圖順序與 Caption、非 IG 僅存 URL 的提示、AI 僅用已取得內容；📝／🤖 辨識結果另存、可捨棄，AI 整理只依辨識結果描述圖片 |
| Search | 搜尋只屬於本人與允許共享白板的資料；停用模組不出現 |
| 1.0 回退 | 2.0 使用後切回 1.0；新欄位不導致同步錯亂 |
| GAS | 部署、授權、初始化、排程心跳、失敗與效能日誌 |

## 優先風險

1. Google Sheets 全表搜尋隨資料增加可能變慢；先量測再決定快取與索引。
2. Cloud-first 的前端佇列／整包同步，任何更動都須追完整讀寫路徑。
3. 連續大 PR 已合併，但 CI 綠燈不等於實機、真實資料與權限完成驗收。
4. UI 上的模組化不等於程式碼實體拆分；不能過早宣稱插件架構。
5. 圖書館資料來源仍有限制；圖片辨識是按需手動、結果未納入搜尋，不能宣稱圖片全文可搜尋。
